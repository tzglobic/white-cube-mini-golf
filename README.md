# White Cube Mini Golf Open

A static web app for a team mini-golf afternoon: team setup, score entry by hole or by team, a projector-sized live leaderboard, stats, a photographed-scorecard reader and a commentator-style match report.

Open the site, choose **Load demo data** to look around, or start a new round in **Setup**. Scores are stored in your own browser only. Optional AI features (reading a scorecard photo, writing and voicing the match report) use API keys that you enter in **Settings**; they are kept in that browser's local storage and are never part of this repository.

Built with Claude. Stingers voiced with ElevenLabs.
